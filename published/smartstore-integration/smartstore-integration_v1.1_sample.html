개요 : 연동정책

개요네이버 스마트 스토어 연동 서비스 분석 ( https://flow.team/l/QLo76 )
블로그페이 관리자에서 스마트스토어 상품을 함께 등록·관리하도록 하여, 판매채널별 상품 이중 관리 부담 해소
적용 범위
  1. 스마트스토어 연결
  2. 상품 연동 (상품 가져오기, 상품 내보내기)
  3. 리뷰 일괄 등록 (엑셀 업로드)
스마트스토어 연결스마트스토어 단일 계정 연결, 네이버 커머스API 대행사로 [블로그페이] 지정 후 연결 가능 ( 네이버 커머스 제휴API 링크 )
연결 해제 시연동 목록에서 상품 미노출 / 스마트스토어 전송이 필요한 모든 처리 불가
기본 원칙상품정보 = 블로그페이 기준 → 상품 가져오기, 상품 내보내기로 수동 전송
재고
  1. 블로그페이·스마트스토어 재고 각각 관리 (재고 연동 없음)
  2. 최초 내보내기 시 블로그페이 재고를 초기값으로 전송 / 이후 내보내기 시 재고 미전송
리뷰 일괄 등록
대상 페이지블로그페이 구매후기 게시판 내 기능 구현
대상 리뷰스마트스토어 문의/리뷰관리 > 리뷰 관리 > 리뷰목록 내 [엑셀다운]을 통해 추출된 리뷰 데이터 (.xlsx)
등록 절차
  1. 엑셀 업로드 → 상품 매칭 → 검증 → 결과 확인
  2. 스마트스토어 연동 상품은 자동 매칭 / 미연동 상품은 판매자가 수동 매칭
  3. 동일 후기를 다시 업로드하면 최신값으로 갱신됨
상품 연동
연동 방식
  • 블로그페이와 스마트스토어의 입력값이 달라 직접 매칭되지 않는 값은 [연동정보]에 저장함
  • 모든 상품정보는 [내보내기] 처리 시점 기준 수동 전송 (재고는 최초 등록 시에만 전송)
연동 정보
공통 정보
  • 판매채널 단위로 한번 설정해 전체 상품에 공통 적용 (필수 입력, 미입력 시 연동실패)
→ 참고) [스마트스토어 연동 07p]
기본 배송설정
  • 상품별 배송비 설정 연동 → [쇼핑몰 배송비 설정 연동] or [개별 설정]
→ 참고) [연동정보 입력항목 12p] / [기본배송 설정별 UI 14p]
배송비 매칭
  • 블로그페이 상품 배송설정 내 배송비 유형을 기준으로 스마트스토어 배송비 유형으로 변환
  • 매칭 불가 유형은 개별 설정 필요
→ 참고) [배송비 설정별 매칭 15p]
추가 배송설정
  • 블로그페이에 없는 스마트스토어 전용 배송 정보 상품 단위로 관리
→ 참고) [연동정보 입력항목 13p]
연동 상태
  • 연동대기 : 스마트스토어에 아직 반영되지 않은 상태 (연동정보 입력 전 / 내보내기 처리 대기, 처리 중)
  • 연동완료 : 스마트스토어에 정상 반영된 상태
  • 연동실패 : 전송이 실패한 상태 (사유 해결 후 다시 내보내기)
가져오기
  • 스마트스토어 상품 중 블로그페이에 연동상태가 없는 상품만 신규 등록
  • 가져온 상품은 [전시중지]로 등록, 이미 연동된 상품은 제외
  • 배송정보 = 연동정보 [개별 설정]으로 저장 / 상품정보 = 기본 배송비 적용 / 공통정보 = 블로그페이 기준 적용
→ 참고) [상품 가져오기 17p]
내보내기
  • 신규 상품 : [연동대기]로 등록 (전송 안 함) → 연동정보 입력 후 다시 내보내기 시 스마트스토어에 생성
  • 연동 상품 : 블로그페이 정보로 수정 전송
  • 연동 이후에는 블로그페이 → 스마트스토어 일방향 (가져오기로 갱신하지 않음)
연동해제연동정보, 연동상태 삭제 / 연동상품관리 목록에서 제외 / 블로그페이 상품정보는 유지
