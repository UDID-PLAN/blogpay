쇼핑 DBURL 설정(Beta)

    네이버 지식쇼핑 또는 다음 쇼핑하우 광고를 진행하실 경우만 설정하시면 됩니다.

    1. DBURL 설정
  • 네이버 쇼핑 또는 다음 쇼핑하우로 상품정보를 전달할 DBURL을 설정합니다.
  • 네이버 쇼핑 또는 다음 쇼핑하우 서비스를 이용하는 고객이 사용할 수 있습니다.
  • 네이버 쇼핑 또는 다음 쇼핑하우 신청을 진행 중이거나 완료된 경우 반드시 DBURL 설정을 [사용함]으로 설정해야 합니다.
  • DBURL 설정을 [사용안함]으로 설정 시, 네이버 쇼핑 또는 다음 쇼핑하우 신청이 진행 중인 경우에는 신청절차가 중단되거나 이미 사용중인 기존 서비스가 중단될 수 있습니다.
    • 2. DBURL 업데이트 안내
  • DBURL 설정을 [사용함]으로 설정한 경우 DBURL 경로 업데이트가 최대 하루까지 소요될 수 있습니다.
  • DBURL 상품정보는 매체사의 업데이트 시간에 따라 반영 시간이 달라질 수 있습니다.
    • 3. DBURL 적용 방법
  • 네이버쇼핑 :
    DBURL 경로는 '네이버 쇼핑 파트너존(관리자) > 상품관리 > 상품정보 수신 현황'에서 등록 요청 버튼 클릭 후 팝업에 입력합니다.
    DBURL 생성이 완료되면 DBURL 우측에 업데이트 시간이 표기됩니다. DBURL 생성이 완료된 후에 네이버에 등록하시기 바랍니다.
    DBURL 경로가 업데이트 되지 않는 경우에는 다시 저장 버튼을 클릭합니다
  • 다음 쇼핑하우 :
    상품URL 생성이 완료되면 shophow@daumcorp.com 으로 전달해주시기 바랍니다.
    업데이트 스케줄은 하루에1번, 수집시각은 입점시 협의에 의해 결정합니다.
    수집 시 UTF-8로 수집되도록 쇼핑하우에 요청바랍니다.
    • 4. DBURL 필수 항목
  • 아래의 항목은 반드시 값이 존재해야 하며 값이 없을 경우 등록이 되지 않으니 다시 한번 확인하여 주세요.
  • 상품 등록시 카테고리 지정(필수)해야 정상 등록됩니다.
  • 네이버쇼핑 :
    해외 아이콘을 사용하실 경우 상품등록 시 개인 통관번호를 '사용'으로 설정하셔야 합니다.
    title : 상품명, price_pc : 상품가격( 0원 인경우 값이 없는것으로 판단합니다.)
  • 다음 쇼핑하우 :
    pname : 상품명, price : 상품가격( 0원 인경우 값이 없는것으로 판단합니다.),igurl : 이미지
