할 일

  1. 제품 추가 방법 : [데이터 파일 업로드] → [다음]
  2. 파일 형식 : 커머스 관리자
  3. 파일 업로드 방법 : [URL 또는 Google 스프레드시트 사용] → 피드URL 경로 입력 → [다음]
  4. 설정 확인 : 기본 통화·빈도 선택 → [업로드]

입력값

  • URL : 블로그페이 피드URL 경로
  • 기본 통화 : KRW - 대한민국 원
  • 빈도 : 매시간

주의사항

  • 로그인 상세 정보(사용자 이름·비밀번호) : 비워 둠 (피드URL 보호 방식 확정 후 수정)
  • 업로드 일정은 바꾸기로 등록 : 피드에 없는 상품은 카탈로그에서 삭제
