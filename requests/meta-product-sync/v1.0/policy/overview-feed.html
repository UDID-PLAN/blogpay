기준
블로그페이 상품정보를 기준으로 보냅니다. 상품 1개 = 피드 1행이며, 옵션 조합별로 나누지 않고 옵션값은 보내지 않습니다.
반영 흐름
상품 등록·수정·삭제 → 피드 다시 만들기 (1시간마다) → Meta 수집 (판매자가 정한 주기, 매시간 안내) → 카탈로그 반영
업로드 방식
바꾸기 : 피드에 없는 상품은 다음 수집 때 카탈로그에서 삭제됩니다. 커머스 관리자에서 피드URL로 카탈로그를 만들면 기본값이 바꾸기입니다.
피드 제외
전시안함·삭제 상품, 아래 필수 값이 없는 상품
Meta 카탈로그 필드블로그페이 상품정보처리 기준
id *상품번호판매자가 바꿀 수 있는 상품코드는 쓰지 않습니다.
item_group_id-보내지 않습니다. 옵션 상품도 대표 상품 정보 1행만 보냅니다.
title *상품명 *그대로 보냅니다.
description *추가 상품 설명값이 없으면 피드에서 제외합니다. 화면 안내 배너에서 필수 입력을 안내합니다.
availability *품절여부블로그페이 품절 기준을 따릅니다. 판매 → in stock / 품절 → out of stock
condition *-new로 고정합니다.
price * / sale_price이전 판매가 / 판매가 *이전 판매가가 판매가보다 크면 price = 이전 판매가, sale_price = 판매가. 아니면 price = 판매가. 형식 : 1000 KRW
link *상품 URL쇼핑몰 상품 상세 주소를 보냅니다. 단축주소(bp2.kr)는 쓰지 않습니다.
image_link *대표 이미지그대로 보냅니다.
brand *브랜드 / 제조사 / 상점명브랜드가 없으면 제조사, 제조사도 없으면 상점명을 보냅니다.
google_product_category-보내지 않습니다.
블로그페이 상품 상태피드Meta 카탈로그
판매포함 (in stock)노출
품절포함 (out of stock)품절로 표시, 상품 유지
전시안함 · 삭제제외다음 수집 때 삭제
필수 값 없음 (상품명 · 추가 상품 설명 · 판매가 0원 · 대표 이미지)제외등록되지 않음

* 필수 값 · 근거 : Meta Catalog Reference, 블로그페이 개발자 문서 (상품)
