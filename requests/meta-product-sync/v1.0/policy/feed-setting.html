피드 기준
상품 1개 = 피드 1행 (옵션값 미전송)
업로드 방식
바꾸기 : 피드에 없는 상품은 다음 수집 때 카탈로그에서 삭제
피드 제외
전시안함·삭제 상품, 필수 값이 없는 상품
Meta 카탈로그 필드블로그페이 상품정보비고
id *상품번호
title *상품명
description *추가 상품 설명값 없으면 피드 제외
availability *품절여부
condition *-new 고정
price * / sale_price이전 판매가 / 판매가
link *상품 URL
image_link *대표 이미지값 없으면 피드 제외
brand *브랜드 / 제조사 / 상점명브랜드 값이 없으면 브랜드 → 제조사 → 상점명 순으로 전송
additional_image_link추가 이미지값 있으면 전송
product_type쇼핑몰 카테고리명값 있으면 전송

* Meta 필수 값 · 근거 : Meta Catalog Reference
