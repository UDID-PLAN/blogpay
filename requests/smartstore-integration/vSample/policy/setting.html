연결 계정
스마트스토어 단일 계정 연결. 네이버 커머스API 대행사로 [블로그페이]를 지정한 뒤 연결 가능 (네이버 커머스 제휴API 링크)
연결 정보
스마트스토어 URL ID / API 연동용 판매자 ID. 연결 완료 이후에는 값을 수정할 수 없고, 해제 후 재연결해야 함
연결 해제 시
연동 목록에서 상품 미노출 / 스마트스토어 전송이 필요한 모든 처리 불가
판매자정보 업데이트
스마트스토어 API 내 ID 값으로만 입력 가능한 정보(주소록, 배송비 묶음그룹)를 블로그페이로 불러옴. 스마트스토어 내 템플릿 정보가 바뀌면 다시 눌러 최신값 반영
공통 정보
판매채널 단위로 한번 설정해 전체 상품에 공통 적용 (필수 입력, 미입력 시 연동실패). 상품 내보내기·가져오기 모두 적용되며, 스마트스토어 상품을 가져올 때도 블로그페이 공통 설정 기준으로 저장
