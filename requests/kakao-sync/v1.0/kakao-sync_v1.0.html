화면 설명
카카오 계정 로그인에 안내 배너와 연동 방식(카카오로그인 / 카카오싱크) 선택을 추가합니다.
  1. 1
    사용함 / 사용안함
    • 사용함을 선택하면 아래 설정 영역이 보입니다.
    • 사용안함이면 쇼핑몰에 카카오 로그인 버튼이 노출되지 않습니다.
  2. 2
    버튼 - 개발자센터 / 이용매뉴얼
    • 개발자센터는 카카오 디벨로퍼스를 새 창으로 엽니다.
    • 이용매뉴얼에서 카카오로그인·카카오싱크 설정 방법을 안내합니다.
  3. 3
    안내 배너
    • 두 방식의 차이와 카카오싱크 이용 조건을 안내합니다.
  4. 4
    버튼 - 카카오로그인 / 카카오싱크
    • 기본값은 카카오로그인입니다.
    • 개인 판매회원은 카카오싱크를 선택할 수 없습니다. (페이앱 회원 유형 기준)
  5. 5
    REST API Key
    • 두 방식 모두 같은 키를 씁니다. 방식을 바꿔도 입력값은 유지됩니다.
  6. 6
    버튼 - 저장
    • 연동 방식을 바꿔 저장하면 확인 알림이 뜹니다.
  1. 1
    알림 - 카카오싱크로 변경
    • 카카오싱크를 선택하고 저장하면 노출됩니다.
    • 확인을 누르면 저장되고, 취소하면 저장하지 않습니다.
  2. 2
    버튼 - 저장
    • 알림이 뜨는 버튼입니다.
  1. 1
    알림 - 카카오로그인으로 변경
    • 카카오싱크에서 카카오로그인으로 바꿔 저장하면 노출됩니다.
    • 확인을 누르면 저장되고, 취소하면 저장하지 않습니다.
  2. 2
    버튼 - 저장
    • 알림이 뜨는 버튼입니다.
이용 대상
카카오로그인 : 전체 판매회원
카카오싱크 : 사업자 판매회원 (페이앱 회원 유형 기준)
연동 방식
독립몰 방식. 판매자가 카카오 디벨로퍼스에서 앱·채널·약관을 직접 설정하고 블로그페이에 REST API Key를 입력
입력값
REST API Key 1개 (두 방식 공통)
방식 전환
카카오로그인 ↔ 카카오싱크 양방향 허용. 같은 카카오 앱을 쓰면 기존 카카오 가입 회원은 그대로 로그인
카카오 측 설정
간편가입 사용 여부는 카카오 앱 설정이라 블로그페이에서 변경 불가. 카카오로그인으로 바꾸면 판매자가 카카오 디벨로퍼스에서 간편가입을 해제
서비스 약관 태그
이용약관·개인정보처리방침·만 14세 이상 약관의 고정 태그값 [약관태그]를 개발팀에서 정의, 이용매뉴얼로 판매자에게 안내
리다이렉트 URI
기존 카카오 로그인 [리다이렉트 URI] 유지
개인정보 동의항목 심사
판매자가 개인정보 동의항목 심사를 직접 진행하므로, 심사를 받지 않았거나 반려된 상태에서도 카카오싱크를 사용할 수 있음. 이 경우 고객 가입 시 오류가 발생하는지, 어떻게 처리되는지 확인 필요
서비스 약관 태그
판매자가 카카오 디벨로퍼스에서 서비스 약관 태그를 직접 입력하므로, 블로그페이 서버가 동의 여부를 확인할 고정 태그값(이용약관·개인정보처리방침·만 14세 이상)을 개발팀에서 정해 전달 필요

화면 설명
카카오 로그인 아래에 연동방식 선택을 추가합니다. 정책과 알림은 PRO와 같습니다.
  1. 1
    버튼 - 개발자센터 / 이용매뉴얼
    • PRO와 같습니다. 이용매뉴얼에서 카카오로그인·카카오싱크 설정 방법을 안내합니다.
  2. 2
    연동방식
    • 카카오 로그인을 사용으로 두면 보입니다. 기본값은 카카오로그인입니다.
    • 개인 판매회원은 카카오싱크를 선택할 수 없습니다. (페이앱 회원 유형 기준)
  3. 3
    REST API Key
    • 두 방식 모두 같은 키를 씁니다.
  4. 4
    버튼 - 저장
    • 연동 방식을 바꿔 저장하면 PRO와 같은 확인 알림이 뜹니다.
정책
PRO와 동일 (이용 대상·방식 전환·알림)
화면 차이
카카오 로그인 [사용] 아래에 연동방식 행 추가. 개발자센터·이용매뉴얼 버튼은 상단 로고 목록 위치 유지
판매자 설정 단계 (카카오싱크)
카카오싱크 이용을 위한 판매자 설정 순서
  • 판매자가 카카오디벨로퍼스·카카오비즈니스 파트너센터에서 앱·채널·약관을 직접 설정한 뒤, 블로그페이 관리자에 REST API 키를 입력해 연동
  • 심사 3건을 순서대로 진행: 비즈니스 채널 심사 → 앱-채널 연결 심사 → 개인정보 동의항목 심사 (각 영업일 3~5일, 최소 영업일 9~15일)
  • STEP 1과 STEP 2는 동시에 진행 가능. 메뉴 명칭은 2026-11 카카오 문서 기준
단계설정 위치할 일입력값 (블로그페이 기준)주의사항
STEP 0
사전 확인		-이용 조건 확인
  • 페이앱 사업자 회원 여부 / 사업자등록번호
  • 카카오 로그인 사용 중이면 기존 앱 확인
 개인 판매회원은 이용 불가 (카카오 앱·채널에 사업자번호 필요)
STEP 1
앱 준비·기본 설정
(대기 없음)		카카오디벨로퍼스
  1. 기존 앱 선택 또는 앱 생성
  2. [앱] > [일반] > 비즈니스 정보 > [사업자 정보 등록] : 비즈 앱 전환
  3. [카카오 로그인] > [일반] > 사용 설정 : 사용(ON)
  4. [앱] > [플랫폼 키] > [REST API 키] > 로그인 리다이렉트 URI : URI 등록 > 클라이언트 시크릿 : 모두 사용안함(OFF)
  5. [카카오 로그인] > [고급] > 로그아웃 리다이렉트 URI : URI 등록
  6. [앱] > [추가 기능 신청] > 신청 자격 확인 > [신청 자격 확인] : 추가 기능 신청 자격 확인
  • 앱 이름: 쇼핑몰 이름
  • 회사명: 상호
  • 아이콘: 쇼핑몰 로고
  • 사업자등록번호: 페이앱 사업자 정보
  • 리다이렉트 URI : [리다이렉트 URI] (개인 도메인 연결 시 함께 추가)
  • 카카오 로그인 사용 중이면 반드시 기존 앱 사용 (새 앱은 기존 회원이 재가입 처리됨)
  • 앱 이름, 아이콘, 회사명은 고객 동의 화면에 노출
  • REST API 키는 클라이언트 시크릿이 켜진 상태로 생성되므로 꺼야 함
  • 비즈 앱 전환은 심사 없음
  • 기존 카카오 로그인 이용자는 2·6번만 새로 진행
STEP 2
비즈니스 채널 준비
(심사 3~5일)		카카오비즈니스 파트너센터
  1. 기존 카카오톡 채널 선택 또는 채널 개설
  2. [채널] > [비즈니스 심사] > [채널 심사 신청하기] : 비즈니스 채널 전환
  • 채널 이름: 쇼핑몰 이름
  • 사업자 정보: 페이앱 사업자 정보
  • 채널 마스터만 신청 가능
  • 제한 업종은 신청 불가 (채널 노출 X, 프로필·이메일만 수집)
  • 심사 기간 발생
STEP 3
앱-채널 연결
(심사 3~5일)		카카오디벨로퍼스 [앱] > [추가 기능 신청] > 카카오톡 채널 연결 > [신청] : STEP 2 채널 선택 후 연결 신청 STEP 2에서 승인된 비즈니스 채널
  • STEP 1, 2 완료 후 신청 가능
  • 앱과 채널의 사업자 정보가 같아야 승인
  • 앱 오너·에디터 계정만 신청 가능
  • 심사 기간 발생
STEP 4
비즈니스 정보·개인정보 동의항목 신청
(심사 3~5일)		카카오디벨로퍼스 [앱] > [추가 기능 신청]
  1. 비즈니스 정보 > [신청]
  2. 개인정보 동의항목 > [신청]
 개인정보
  • 이름 : 필수동의
  • 카카오계정(전화번호) : 필수동의
  • 배송지정보 : 선택동의
  • 회원가입 링크 : /member/join
  • 개인정보처리방침 : /userpage/agree_detail1
  • 회원가입 화면 : 쇼핑몰 관련 페이지 캡처 (개인정보 주의)
  • 회원가입 페이지 : /member/join
  • 로그인 페이지 : /member/login
  • 회원탈퇴 페이지 : /member/mypage
  • 수집 사유 : 회원 식별, 주문·배송 안내
  • STEP 3 승인 시 비즈니스 정보는 자동 승인
  • 개인정보 동의항목 신청 건만 심사 기간 발생
  • 가입 화면의 필수·선택 여부가 신청 내용과 같아야 승인
STEP 5
동의항목·간편가입 설정
(대기 없음)		카카오디벨로퍼스 [카카오 로그인] > [동의항목]
  1. 대표 채널 > [대표 채널 선택] : STEP 2 채널 선택
  2. 개인정보 : 항목별 동의 여부 선택
[카카오 로그인] > [간편가입]
  1. [서비스 약관 추가] : 약관 추가
  2. [만 14세 이상 연령 동의 추가] : 약관 추가
  3. 사용 설정 : 사용(ON)
 동의항목
  • 닉네임 : 선택동의
  • 카카오계정(이메일) : 필수동의 (계정정보 입력 요청 체크)
  • 카카오톡 채널 추가 : 선택동의
서비스약관
  • 이용약관 URL : /userpage/agree_detail
  • 만 14세 이상 URL : 개인정보처리방침 URL (제9조 14세 미만 아동의 개인정보보호)
  • 동의단계 : 필수동의
  • 태그 : 블로그페이 지정값
  • STEP 4 승인 후 이름, 전화번호, 배송지 설정 상태 확인
  • 대표 채널 미지정 시 동의 화면에 채널 추가 미노출
  • 태그가 블로그페이 지정값과 다르면 정상 가입 처리 불가
STEP 6
블로그페이 연동		블로그페이 관리자 [환경설정] > [연동설정] > [SNS로그인연동 관리] > 카카오 계정 로그인 : REST API 키 입력 → 저장 STEP 1 앱의 REST API 키 저장 후 쇼핑몰 [회원가입] > [카카오 간편가입]에서 작동 확인
