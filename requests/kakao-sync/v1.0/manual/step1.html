할 일

  1. 기존 앱 선택 또는 앱 생성
  2. [앱] > [일반] > 비즈니스 정보 > [사업자 정보 등록] : 비즈 앱 전환
  3. [카카오 로그인] > [일반] > 사용 설정 : 사용(ON)
  4. [앱] > [플랫폼 키] > [REST API 키] > 로그인 리다이렉트 URI : URI 등록 > 클라이언트 시크릿 : 모두 사용안함(OFF)
  5. [카카오 로그인] > [고급] > 로그아웃 리다이렉트 URI : URI 등록
  6. [앱] > [추가 기능 신청] > 신청 자격 확인 > [신청 자격 확인] : 추가 기능 신청 자격 확인

입력값 (블로그페이 기준)

  • 앱 이름: 쇼핑몰 이름
  • 회사명: 상호
  • 아이콘: 쇼핑몰 로고
  • 사업자등록번호: 페이앱 사업자 정보
  • 리다이렉트 URI : [리다이렉트 URI] (개인 도메인 연결 시 함께 추가)

주의사항

  • 카카오 로그인 사용 중이면 반드시 기존 앱 사용 (새 앱은 기존 회원이 재가입 처리됨)
  • 앱 이름, 아이콘, 회사명은 고객 동의 화면에 노출
  • REST API 키는 클라이언트 시크릿이 켜진 상태로 생성되므로 꺼야 함
  • 비즈 앱 전환은 심사 없음
  • 기존 카카오 로그인 이용자는 2·6번만 새로 진행
