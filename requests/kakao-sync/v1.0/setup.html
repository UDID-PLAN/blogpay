개요판매자가 카카오디벨로퍼스·카카오비즈니스 파트너센터에서 앱·채널·약관을 직접 설정한 뒤, 블로그페이 관리자에 REST API Key를 입력해 연동
심사 3건 순서대로 진행 : 비즈니스 채널 심사 → 앱-채널 연결 심사 → 개인정보 동의항목 심사 (각 영업일 3~5일, 최소 영업일 9~15일)
STEP 1과 STEP 2는 동시에 진행 가능. 메뉴 명칭은 2026-11 카카오 문서 기준
기존 이용자기존 카카오 로그인 이용 판매자는 기존 앱을 그대로 사용하며, STEP 1의 비즈 앱 전환·추가 기능 신청 자격 확인부터 새로 진행
단계설정 위치할 일입력값 (블로그페이 기준)주의사항

STEP 1

(대기 없음)		카카오디벨로퍼스
  1. 기존 앱 선택 또는 앱 생성
  2. [앱] > [일반] > 비즈니스 정보 > [사업자 정보 등록] : 비즈 앱 전환
  3. [카카오 로그인] > [일반] > 사용 설정 : 사용(ON)
  4. [앱] > [플랫폼 키] > [REST API 키] > 로그인 리다이렉트 URI 등록, 클라이언트 시크릿 모두 사용안함(OFF)
  5. [카카오 로그인] > [고급] > 로그아웃 리다이렉트 URI 등록
  6. [앱] > [추가 기능 신청] > [신청 자격 확인]

회사명 : 상호
아이콘 : 쇼핑몰 로고
사업자등록번호 : 페이앱 사업자 정보
리다이렉트 URI : [리다이렉트 URI] (개인 도메인 연결 시 함께 추가)		카카오 로그인 사용 중이면 반드시 기존 앱 사용 (새 앱은 기존 회원이 재가입 처리됨)
앱 이름·아이콘·회사명은 고객 동의 화면에 노출
