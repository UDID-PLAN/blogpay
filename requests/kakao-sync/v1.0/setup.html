설정 순서
  • 판매자가 카카오디벨로퍼스·카카오비즈니스 파트너센터에서 앱·채널·약관을 직접 설정한 뒤, 블로그페이 관리자에 REST API 키를 입력해 연동
  • 심사 3건을 순서대로 진행: 비즈니스 채널 심사 → 앱-채널 연결 심사 → 개인정보 동의항목 심사 (각 영업일 3~5일, 최소 영업일 9~15일)
  • STEP 1과 STEP 2는 동시에 진행 가능. 메뉴 명칭은 2026-11 카카오 문서 기준
  1. STEP 0사전 확인설정 위치 : -

    할 일

    이용 조건 확인

    입력값 (블로그페이 기준)

    • 페이앱 사업자 회원 여부 / 사업자등록번호
    • 카카오 로그인 사용 중이면 기존 앱 확인

    주의사항

    개인 판매회원은 이용 불가 (카카오 앱·채널에 사업자번호 필요)
  2. STEP 1앱 준비·기본 설정대기 없음설정 위치 : 카카오디벨로퍼스

    할 일

    1. 기존 앱 선택 또는 앱 생성
    2. [앱] > [일반] > 비즈니스 정보 > [사업자 정보 등록] : 비즈 앱 전환
    3. [카카오 로그인] > [일반] > 사용 설정 : 사용(ON)
    4. [앱] > [플랫폼 키] > [REST API 키] > 로그인 리다이렉트 URI : URI 등록 > 클라이언트 시크릿 : 모두 사용안함(OFF)
    5. [카카오 로그인] > [고급] > 로그아웃 리다이렉트 URI : URI 등록
    6. [앱] > [추가 기능 신청] > 신청 자격 확인 > [신청 자격 확인] : 추가 기능 신청 자격 확인

    입력값 (블로그페이 기준)

    • 앱 이름: 쇼핑몰 이름
    • 회사명: 상호
    • 아이콘: 쇼핑몰 로고
    • 사업자등록번호: 페이앱 사업자 정보
    • 리다이렉트 URI : [리다이렉트 URI] (개인 도메인 연결 시 함께 추가)

    주의사항

    • 카카오 로그인 사용 중이면 반드시 기존 앱 사용 (새 앱은 기존 회원이 재가입 처리됨)
    • 앱 이름, 아이콘, 회사명은 고객 동의 화면에 노출
    • REST API 키는 클라이언트 시크릿이 켜진 상태로 생성되므로 꺼야 함
    • 비즈 앱 전환은 심사 없음
    • 기존 카카오 로그인 이용자는 2·6번만 새로 진행
  3. STEP 2비즈니스 채널 준비심사 3~5일설정 위치 : 카카오비즈니스 파트너센터

    할 일

    1. 기존 카카오톡 채널 선택 또는 채널 개설
    2. [채널] > [비즈니스 심사] > [채널 심사 신청하기] : 비즈니스 채널 전환

    입력값 (블로그페이 기준)

    • 채널 이름: 쇼핑몰 이름
    • 사업자 정보: 페이앱 사업자 정보

    주의사항

    • 채널 마스터만 신청 가능
    • 제한 업종은 신청 불가 (채널 노출 X, 프로필·이메일만 수집)
    • 심사 기간 발생
  4. STEP 3앱-채널 연결심사 3~5일설정 위치 : 카카오디벨로퍼스

    할 일

    [앱] > [추가 기능 신청] > 카카오톡 채널 연결 > [신청] : STEP 2 채널 선택 후 연결 신청

    입력값 (블로그페이 기준)

    STEP 2에서 승인된 비즈니스 채널

    주의사항

    • STEP 1, 2 완료 후 신청 가능
    • 앱과 채널의 사업자 정보가 같아야 승인
    • 앱 오너·에디터 계정만 신청 가능
    • 심사 기간 발생
  5. STEP 4비즈니스 정보·개인정보 동의항목 신청심사 3~5일설정 위치 : 카카오디벨로퍼스

    할 일

    [앱] > [추가 기능 신청]
    1. 비즈니스 정보 > [신청]
    2. 개인정보 동의항목 > [신청]

    입력값 (블로그페이 기준)

    개인정보
    • 이름 : 필수동의
    • 카카오계정(전화번호) : 필수동의
    • 배송지정보 : 선택동의
    • 회원가입 링크 : /member/join
    • 개인정보처리방침 : /userpage/agree_detail1
    • 회원가입 화면 : 쇼핑몰 관련 페이지 캡처 (개인정보 주의)
    • 회원가입 페이지 : /member/join
    • 로그인 페이지 : /member/login
    • 회원탈퇴 페이지 : /member/mypage
    • 수집 사유 : 회원 식별, 주문·배송 안내

    주의사항

    • STEP 3 승인 시 비즈니스 정보는 자동 승인
    • 개인정보 동의항목 신청 건만 심사 기간 발생
    • 가입 화면의 필수·선택 여부가 신청 내용과 같아야 승인
  6. STEP 5동의항목·간편가입 설정대기 없음설정 위치 : 카카오디벨로퍼스

    할 일

    [카카오 로그인] > [동의항목]
    1. 대표 채널 > [대표 채널 선택] : STEP 2 채널 선택
    2. 개인정보 : 항목별 동의 여부 선택
    [카카오 로그인] > [간편가입]
    1. [서비스 약관 추가] : 약관 추가
    2. [만 14세 이상 연령 동의 추가] : 약관 추가
    3. 사용 설정 : 사용(ON)

    입력값 (블로그페이 기준)

    동의항목
    • 닉네임 : 선택동의
    • 카카오계정(이메일) : 필수동의 (계정정보 입력 요청 체크)
    • 카카오톡 채널 추가 : 선택동의
    서비스약관
    • 이용약관 URL : /userpage/agree_detail
    • 만 14세 이상 URL : 개인정보처리방침 URL (제9조 14세 미만 아동의 개인정보보호)
    • 동의단계 : 필수동의
    • 태그 : 블로그페이 지정값

    주의사항

    • STEP 4 승인 후 이름, 전화번호, 배송지 설정 상태 확인
    • 대표 채널 미지정 시 동의 화면에 채널 추가 미노출
    • 태그가 블로그페이 지정값과 다르면 정상 가입 처리 불가
  7. STEP 6블로그페이 연동설정 위치 : 블로그페이 관리자

    할 일

    [환경설정] > [연동설정] > [SNS로그인연동 관리] > 카카오 계정 로그인 : REST API 키 입력 → 저장

    입력값 (블로그페이 기준)

    STEP 1 앱의 REST API 키

    주의사항

    저장 후 쇼핑몰 [회원가입] > [카카오 간편가입]에서 작동 확인
