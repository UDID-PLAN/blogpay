이용 대상
카카오로그인 : 전체 판매회원
카카오싱크 : 사업자 판매회원 (페이앱 회원 유형 기준)
연동 방식
독립몰 방식. 판매자가 카카오 디벨로퍼스에서 앱·채널·약관을 직접 설정하고 블로그페이에 REST API Key를 입력
입력값
REST API Key 1개 (두 방식 공통)
방식 전환
카카오로그인 ↔ 카카오싱크 양방향 허용. 같은 카카오 앱을 쓰면 기존 카카오 가입 회원은 그대로 로그인
카카오 측 설정
간편가입 사용 여부는 카카오 앱 설정이라 블로그페이에서 변경 불가. 카카오로그인으로 바꾸면 판매자가 카카오 디벨로퍼스에서 간편가입을 해제
서비스 약관 태그
이용약관·개인정보처리방침·만 14세 이상 약관의 고정 태그값 [약관태그]를 개발팀에서 정의, 이용매뉴얼로 판매자에게 안내
리다이렉트 URI
기존 카카오 로그인 [리다이렉트 URI] 유지
