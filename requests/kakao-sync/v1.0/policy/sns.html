이용 대상
카카오로그인 : 전체 판매회원 / 카카오싱크 : 사업자 판매회원 (페이앱 회원 유형 기준)
연동 방식
카카오 계정 로그인 [사용함] 시 카카오로그인 / 카카오싱크 중 1개 선택. 기본값 카카오로그인
입력값
REST API Key 1개 (두 방식 공통). 방식 변경 시 입력값 유지
방식 전환
양방향 허용. 같은 카카오 앱 사용 시 기존 카카오 가입 회원 로그인 유지
저장
하단 [저장] 클릭 시 반영. 연동 방식이 바뀐 경우 확인 알림 후 저장
이용매뉴얼
카카오 계정 로그인 [이용매뉴얼]에 카카오로그인·카카오싱크 판매자 설정 방법 통합 (개요 > 판매자 설정 단계 참고)
