개요신규 가입 판매자가 관리자에 처음 접속하면 BASIC이 아니라 PRO 메인으로 연결하고, PRO 화면 위에서 튜토리얼(둘러보기 + 기초설정)을 진행합니다.
BASIC · PRO 두 버전을 하나로 통합하기 위한 1단계이며, BASIC 클로징은 추후 논의합니다.

AS-IS
최초 접속이용 동의 안내 → BASIC 메인 + BASIC 튜토리얼
PRO 메인튜토리얼 없음
둘러보기3장 : BASIC/PRO 모드, SNS 주문서 폼, 상세페이지
기초설정기본정보 → 배송비(추천 / 직접 입력, 도서산간 2개 화면) → 결제(결제수단, 무통장 2개 화면) → 최종확인
닫기✕ 버튼 → 알림 "배송비 설정까지는 튜토리얼은 종료되지 않습니다."
TO-BE
최초 접속이용 동의 안내 → PRO 메인 + 튜토리얼
BASIC 전환상단 [BASIC 바로가기]로 전환 (기존과 동일)
튜토리얼시작하기 → 둘러보기(4장) → 기초설정(기본정보 → 배송비 → 결제 → 최종확인) → 판매시작
닫기✕ 버튼 없음. 모달 바깥 영역 클릭 시 종료 불가 알림
노출 · 종료 기준
적용 대상신규 가입 판매자 (기존 판매자 제외)
노출 시점튜토리얼을 종료하기 전까지 관리자 접속 시마다 노출
종료 기준기초설정 최종확인에서 [완료]를 누르면 종료, 이후 노출 안 함
새로고침 · 브라우저 종료 · 페이지 이탈은 종료가 아님 → 다음 접속 시 다시 노출
화면PRO 관리자 모달 UI 기준. 튜토리얼 모달 크기는 모두 같게 통일 (이용 동의는 기존 모달 유지)
안내 문구에 PRO · BASIC 구분을 표시하지 않음 (두 화면의 설정값이 같음)
입력값튜토리얼 입력값 = 관리자 설정 메뉴의 값. BASIC · PRO 어느 화면에서 봐도 같은 값
기초설정 저장 위치 (PRO 관리자)
이용 동의마케팅 활용 및 광고성 정보 수신 동의(선택) → 환경설정 > 기본정보 > 마케팅 광고 수신 설정
STEP 1 기본정보쇼핑몰 이름, 대표자명, 고객센터, 팩스번호, 이메일, 이메일 수신 여부, 주소, 회사명, 사업자등록번호, 통신판매업신고번호 → 환경설정 > 기본정보
STEP 2 배송비기본 배송비(고정 배송비 · 금액 · 무료조건) → 환경설정 > 운영정책 > 배송관련설정 > 배송비 리스트 '기본배송비'
장바구니 배송비 · 도서산간 배송여부 · 도서산간 배송비 → 배송관련설정 > 장바구니 설정 및 도서산간 배송비 설정
STEP 3 결제결제수단 → 환경설정 > 운영정책 > 결제설정 > 결제수단
무통장 사용 여부 · 입금 계좌 → 결제설정 > 무통장 계좌 설정
