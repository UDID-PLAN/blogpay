화면 설명
관리자 최초 접속 시 기존 이용 동의 안내를 그대로 띄웁니다. 동의 후 PRO 메인과 튜토리얼로 이어집니다.
  1. 1
    동의 항목
    • 기존 이용 동의 항목 유지 : [필수] 3개, [선택] 1개
    • 전체 동의 체크 시 4개 항목 모두 체크
    • [보기] 클릭 시 항목별 상세 내용 노출
  2. 2
    [선택] 마케팅 활용 및 광고성 정보 수신 동의
    • 동의 여부는 환경설정 > 기본정보 > 마케팅 광고 수신 설정에 반영
  3. 3
    버튼 - 동의하고 이용하기
    • 필수 항목 3개 모두 동의 시 PRO 메인으로 이동하고 튜토리얼 시작 화면 노출
동의 항목
기존 이용 동의 안내 항목·문구 그대로 사용 ([필수] 3개, [선택] 1개)
노출
관리자 최초 접속 1회. 동의하지 않으면 관리자 이용 불가 (기존과 동일)
동의 후
PRO 메인으로 이동하고 튜토리얼 시작 화면 노출
마케팅 수신
[선택] 동의 여부 → 기본정보 마케팅 광고 수신 설정에 반영
