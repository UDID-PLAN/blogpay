연동정책
개요카카오싱크 연동 개발 요청 ( https://flow.team/l/Q5tmr )
블로그페이 SNS로그인연동 관리에 카카오싱크 방식을 추가하여, 쇼핑몰 고객이 카카오 동의 화면에서 약관 동의와 회원가입을 한 번에 마칠 수 있도록 함
적용 범위
  1. 관리자 SNS로그인연동 관리 (PRO·BASIC) : 연동 방식(카카오로그인 / 카카오싱크) 선택 추가
  2. 카카오 계정 로그인 이용매뉴얼 : 카카오싱크 판매자 설정 방법 추가
  3. 쇼핑몰 기본 개인정보처리방침 : 간편가입 수집항목 수정
  4. 쇼핑몰 카카오 간편가입 처리 (개발)
연동 방식독립몰 방식 : 판매자가 카카오 디벨로퍼스·카카오비즈니스에서 앱·채널·약관을 직접 설정한 뒤, 블로그페이 관리자에 REST API Key를 입력해 연동
호스팅사 방식(카카오싱크 간편설정)은 카카오 제휴 진행 불가로 적용하지 않음
구분카카오 로그인 (기존)카카오싱크 (신규)
고객 화면카카오 계정으로 쇼핑몰 회원가입·로그인카카오 동의 화면에서 쇼핑몰 약관 동의와 회원가입을 한 번에 진행
이용 대상전체 판매회원사업자 판매회원 (개인 판매회원 선택 불가)
판매자 사전 설정카카오 디벨로퍼스 앱 생성, 리다이렉트 URI 등록, 카카오 로그인 사용 설정 (기존 이용매뉴얼 기준)카카오 로그인 설정 + 비즈 앱 전환, 비즈니스 채널, 앱-채널 연결, 개인정보 동의항목 심사, 간편가입 설정
심사 3건 순차 진행 (각 영업일 3~5일)
블로그페이 입력값REST API Key 1개 (두 방식 공통)
방식 전환
  • 카카오로그인 ↔ 카카오싱크 양방향 전환 허용
  • 같은 카카오 앱을 사용하면 고객의 카카오 회원번호가 유지되어 기존 카카오 가입 회원은 그대로 로그인 가능
  • 다른 앱으로 변경 시 기존 회원 연결이 끊김 → 안내 배너로 안내
카카오 측 설정간편가입 사용 여부는 카카오 앱 설정이므로 블로그페이에서 변경 불가 → 카카오로그인으로 변경 시 판매자가 카카오 디벨로퍼스에서 간편가입 설정 해제 (알림으로 안내)
서비스 약관 태그블로그페이 서버가 동의 여부를 확인할 고정 태그값을 개발팀에서 정의 → 판매자가 카카오 디벨로퍼스 간편가입 설정 시 입력 (이용약관 [약관태그] · 개인정보처리방침 [약관태그] · 만 14세 이상 [약관태그])
리다이렉트 URI기존 카카오 로그인 [리다이렉트 URI] 유지 (개발팀 정의)
판매자 설정 단계
개요판매자가 카카오디벨로퍼스·카카오비즈니스 파트너센터에서 앱·채널·약관을 직접 설정한 뒤, 블로그페이 관리자에 REST API Key를 입력해 연동
심사 3건 순서대로 진행 : 비즈니스 채널 심사 → 앱-채널 연결 심사 → 개인정보 동의항목 심사 (각 영업일 3~5일, 최소 영업일 9~15일)
STEP 1과 STEP 2는 동시에 진행 가능. 메뉴 명칭은 2026-11 카카오 문서 기준
기존 이용자기존 카카오 로그인 이용 판매자는 기존 앱을 그대로 사용하며, STEP 1의 비즈 앱 전환·추가 기능 신청 자격 확인부터 새로 진행

화면 설명
카카오 계정 로그인 [사용함] 시 안내 배너·연동 방식(카카오로그인 / 카카오싱크) 선택 추가
REST API Key 입력란은 기존과 동일
  1. 1
    라디오 - 사용함 / 사용안함
    • 사용함 → 안내 배너·연동 방식·REST API Key 노출
    • 사용안함 → 하위 영역 미노출, 쇼핑몰 카카오 로그인 버튼 미노출 (기존)
  2. 2
    버튼 - 개발자센터 / 이용매뉴얼
    • 개발자센터 → 카카오 디벨로퍼스 새 창 (기존)
    • 이용매뉴얼 → 카카오로그인·카카오싱크 판매자 설정 방법 통합 매뉴얼
    • 매뉴얼 내용 : 개요 > 판매자 설정 단계 기준
  3. 3
    안내 배너
    • 카카오 계정 로그인 [사용함] 시 노출 (사업자·개인 판매회원 동일)
    • 카카오로그인·카카오싱크 차이, 카카오싱크 이용 조건, 기존 카카오 앱 유지 안내
    • 카카오싱크로 전환 시 동일한 카카오 앱을 사용해야 기존 고객이 정상적으로 로그인할 수 있습니다. 문구 강조
  4. 4
    버튼 - 카카오로그인 / 카카오싱크
    • 연동 방식 선택, 기본값 카카오로그인 (기존 카카오 로그인 이용 판매자 포함)
    • 개인 판매회원 → [카카오싱크] 비활성 (선택 불가)
    • 연동 방식 변경 후 [저장] 클릭 시 확인 알림 노출
  5. 5
    REST API Key
    • 두 방식 공통 입력값 1개 (기존 입력란)
    • 연동 방식 변경 시 입력값 유지
  1. 1
    알림 - 카카오싱크로 변경
    • 노출 시점 : 카카오로그인 → [카카오싱크] 선택 후 [저장] 클릭
    • 문구 : 카카오싱크로 변경하시겠습니까? 카카오 디벨로퍼스 설정을 완료하지 않으면 카카오 로그인이 동작하지 않을 수 있습니다.
    • 확인 → 저장 / 취소 → 저장하지 않음
  2. 2
    트리거 버튼
    • [카카오싱크] 선택 후 [저장]
  1. 1
    알림 - 카카오로그인으로 변경
    • 노출 시점 : 카카오싱크 → [카카오로그인] 선택 후 [저장] 클릭
    • 문구 : 카카오 로그인으로 변경하시겠습니까? 카카오 디벨로퍼스에서 간편가입 설정을 해제해 주세요.
    • 확인 → 저장 / 취소 → 저장하지 않음
  2. 2
    트리거 버튼
    • [카카오로그인] 선택 후 [저장]
이용 대상
카카오로그인 : 전체 판매회원 / 카카오싱크 : 사업자 판매회원 (페이앱 회원 유형 기준)
연동 방식
카카오 계정 로그인 [사용함] 시 카카오로그인 / 카카오싱크 중 1개 선택. 기본값 카카오로그인
입력값
REST API Key 1개 (두 방식 공통). 방식 변경 시 입력값 유지
방식 전환
양방향 허용. 같은 카카오 앱 사용 시 기존 카카오 가입 회원 로그인 유지
저장
하단 [저장] 클릭 시 반영. 연동 방식이 바뀐 경우 확인 알림 후 저장
이용매뉴얼
카카오 계정 로그인 [이용매뉴얼]에 카카오로그인·카카오싱크 판매자 설정 방법 통합 (개요 > 판매자 설정 단계 참고)
  • 사업자 판매회원 판별 기준 : 페이앱 회원 유형(개인/사업자) 값 사용 가능 여부 (개발 확인)
  • 카카오싱크 사용 중 판매회원 유형이 사업자 → 개인으로 바뀌는 경우 처리 방식
  • 판매자가 개인정보 동의항목 심사를 직접 진행하므로, 심사를 받지 않았거나 반려된 상태에서도 카카오싱크를 사용할 수 있음. 이 경우 고객 가입 시 오류가 발생하는지, 어떻게 처리되는지 확인 필요
  • 판매자가 카카오 디벨로퍼스에서 서비스 약관 태그를 직접 입력하므로, 블로그페이 서버가 동의 여부를 확인할 고정 태그값(이용약관·개인정보처리방침·만 14세 이상)을 개발팀에서 정해 전달 필요
  • 이용매뉴얼 개편 범위·작성 주체
