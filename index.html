[ 니즈 배경 ] - 팬톡으로 아래와 같이 문의 옴. === 안녕하세요. 블로그페이 쇼핑몰과 Meta 상품 카탈로그 자동 연동 관련 문의드립니다. - 블로그페이 ID: bonitabongbong - 쇼핑몰 도메인: https://dovia.kr - Instagram: @dovia.kr 현재 Meta 도메인 인증과 Instagram Shop 연결은 완료했으며, 카탈로그에 수동 등록한 상품은 릴스 제품 태그 및 쇼핑몰 상세페이지 연결까지 정상 작동합니다. 신상품마다 카탈로그에 별도로 등록하는 번거로움을 줄이고 싶어 아래 내용을 문의드립니다. 1. 블로그페이 상품을 Meta(Facebook·Instagram) 카탈로그에 자동 연동하는 기능이나 제휴 서비스가 있나요? 2. Meta에 등록할 수 있는 상품 피드 URL(CSV·XML 등)을 제공하나요? 제공한다면 설정 방법을 안내 부탁드립니다. 3. 기본 연동 기능이 없다면, 공식 상품 조회 API로 별도 자동 연동 프로그램을 개발해도 되나요? API 이용 신청·권한·비용·제한 사항이 있나요? 4. 신상품 추가뿐 아니라 가격 변경, 품절·판매중지 상태도 자동 반영할 수 있나요? 5. 연동되는 상품 링크를 단축주소(bp2.kr)가 아닌, 인증된 dovia.kr의 상품 상세페이지 주소로 지정할 수 있나요? 가능한 방법과 필요한 절차, 추가 비용을 안내 부탁드립니다. 감사합니다. === - 1번, 2번 에 대해 현재는 지원하지 않고 있는 기능이어서 개발 가능한지 검토 지시 (사장님) [ 검토 결과 ] (이미지) - 개발 외 META 연동으로 환경 설정 등 기획도 필요할것으로 판단됨.
